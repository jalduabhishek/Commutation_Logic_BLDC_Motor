# Three-Phase Inverter Commutation Logic

## Overview

This project implements and visualizes the **commutation logic of a three-phase inverter using MATLAB/Simulink**. The switching sequence is generated based on the electrical angle and displayed using a MATLAB animation.

## Features

* Three-phase commutation logic simulation
* Six-switch inverter switching sequence
* Phases A, B, and C separated by 120°
* Dynamic switching-state visualization
* Rotor/electrical angle animation
* MATLAB and Simulink integration

## Tools Used

* MATLAB
* Simulink
* Simscape Electrical

## Working

```text
Simulink Model
      ↓
Electrical Angle
      ↓
Commutation Logic
      ↓
Six Switching Signals
      ↓
MATLAB Animation
      ↓
Visualize Phase Switching
```

## Applications

Useful for understanding **three-phase inverter commutation, six-step switching, BLDC/PMSM motor drives, and power electronic control systems**.
